# Expanded UI Collection

Codex-UI 0.3.0 adds 35 bundled themes. All artwork is generated locally from repository-owned SVG compositions; no remote brand assets or proprietary fonts are used.

## Liquid glass collection

- **流光水镜 Aqua Lens** ? 清透蓝色折射、圆润光学镜片与低饱和玻璃层构成的液态工作台。
- **极地珍珠 Arctic Pearl** ? 冰白珍珠、淡蓝灰折射与少量紫色偏光形成的精致玻璃主题。
- **珊瑚光谱 Coral Spectrum** ? 珊瑚红、桃橙光晕与深莓色玻璃层构成的高能液态主题。
- **石墨光环 Graphite Orbit** ? 石墨黑背景、银蓝边缘与悬浮玻璃光环组成的高对比专业主题。
- **午夜流波 Midnight Wave** ? 午夜蓝水波、青色光带和深海玻璃层构成的动态感界面。
- **薄荷胶囊 Mint Capsule** ? 薄荷绿胶囊、柔紫折射与珍珠白表面结合的轻盈玻璃界面。
- **兰紫棱镜 Orchid Prism** ? 兰紫色液态镜片、冷蓝折射边缘与深色玻璃面板组成的沉浸界面。
- **晨曦凝胶 Sunrise Gel** ? 珊瑚橙、暖黄色与乳白凝胶质感叠加的柔和液态玻璃主题。

```bash

```

The command regenerates only this collection under `assets/presets/` and leaves legacy themes untouched.
