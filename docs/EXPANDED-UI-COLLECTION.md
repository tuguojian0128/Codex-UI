# 扩展 UI 主题合集 / Expanded UI Collection

[中文](#中文) · [English](#english)

## 中文

Codex-UI 0.3.x 新增 35 套内置 UI，主题总数增加到 61 套。所有背景和预览均由仓库内的 SVG 组合生成，没有使用远程品牌素材或专有字体。

### 液态玻璃合集

- 流光水镜 Aqua Lens
- 兰紫棱镜 Orchid Prism
- 晨曦凝胶 Sunrise Gel
- 石墨光环 Graphite Orbit
- 薄荷胶囊 Mint Capsule
- 珊瑚光谱 Coral Spectrum
- 极地珍珠 Arctic Pearl
- 午夜流波 Midnight Wave

其他主题覆盖终端网格、纸艺看板、极简专注、工程蓝图、电影动态、复古窗口、丝绢卷轴、工作台和全景画布等方向。

重新生成主题资源：

```bash
npm run gen:expanded-ui
```

该命令只会重新生成本合集，不会覆盖旧主题。

## English

Codex-UI 0.3.x adds 35 bundled UI themes and expands the complete library to 61 themes. All artwork and previews are generated from repository-owned SVG compositions without remote brand assets or proprietary fonts.

### Liquid-glass collection

- Aqua Lens
- Orchid Prism
- Sunrise Gel
- Graphite Orbit
- Mint Capsule
- Coral Spectrum
- Arctic Pearl
- Midnight Wave

The rest of the collection covers terminal grids, paper boards, minimal focus layouts, engineering blueprints, cinematic canvases, retro windows, silk scrolls, studios, and full-canvas designs.

Regenerate the collection with:

```bash
npm run gen:expanded-ui
```

The command regenerates only this collection and leaves legacy themes untouched.
